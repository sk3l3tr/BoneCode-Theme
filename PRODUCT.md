# BoneCode

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

A declarative VS Code theme extension: a manifest and JSON files, with no executable code.

## Users

The user works with VS Code and Neovim/LazyVim and uses Glass UI, Cyberpunk Scarlet/Umbra, and Kaolin.

## Product Purpose

Provide two installable BoneCode themes, dark and light, with instructions for setting them up in VS Code.

## Capabilities and Constraints

Colors for the interface, TextMate syntax, semantic tokens, and the terminal. The user explicitly requested pure black for Dark. Editor settings are left untouched, and the extension is not published.

## Brand Commitments

BoneCode's identity and BoneVim's palette, with consistent color roles. Light adjusts accent brightness to maintain readability against ivory backgrounds.

## Evidence on Hand

The current palette at `~/.config/nvim/lua/skeletor/palette.lua`, the `skeletor-cyan.lua` color scheme, the icon reference image, and the three installed reference extensions.
